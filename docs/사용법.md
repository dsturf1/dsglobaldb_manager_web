# 글로벌 DB 사용법 — 웹과 글로벌 DB 봇

> 2026-11-03 기준 · 대상: 글로벌 DB 웹으로 기준 데이터를 관리하는 본사 관리자, 등록 요청을 승인하는 승인자
> 시스템 구조는 [시스템_구성도.md](시스템_구성도.md)

글로벌 DB 는 약품·기타 코드·거래처·창고·인력·장비·골프장 같은 **공통 기준 데이터**를 한 곳에 둡니다. 재고·견적·작업 보고·투입비 앱이 이 데이터를 읽어 씁니다. 여기서 고치면 그 앱들에도 바로 반영됩니다.

---

## 1. 들어가기

- 주소: **https://globaldb.dsturf.net**
- 회사 계정(이메일)으로 로그인합니다. 가입 화면은 없습니다 — 계정이 없으면 관리자에게 요청하세요.
- 위쪽에 소속 조직과 이메일이 보입니다. 본사(전체) 계정은 모든 조직의 데이터를 봅니다.
- 왼쪽 메뉴:

| 메뉴 | 하는 일 |
|---|---|
| **등록 요청** | 재고·견적에서 들어온 새 품목·거래처 요청 보기·승인 (메뉴 옆 숫자 = 승인 대기) |
| **약품정보** | 농약·비료·기타약재 (코드 A·B·C) |
| **기타 코드(잔디/물품)** | 잔디(G)·기타물품(D)·운반비 등 기타(E) — 약품정보와 같은 화면 |
| 인력정보 · 장비정보 | 인력, 장비와 유지보수 이력 |
| **거래처정보** | 거래처 |
| **창고정보** | 창고 (용역 창고는 방제작업코스와 연결) |
| 기본정보 | 직급·조직·날씨·휴일·장비 타입 등 |
| 맵코스 | 골프장 |
| **방제작업코스** | 용역 현장(GC) — 골프장·고객사·용역창고 짝의 원본 |
| 방제기본정보 | 방제 조직·용역·작업·차량 정보 |
| **설정** | 승인자, 텔레그램 연결 |

## 2. 약품정보 · 기타 코드(잔디/물품)

두 화면은 모양과 기능이 같고, 보여 주는 코드만 다릅니다.

### 찾기
- 처음에는 **사용(Y) 품목만** 보입니다. 미사용까지 보려면 **상태** 필터를 '전체'로.
- 위쪽 검색칸(제품명)과 필터(중요도 · 대분류 · 중분류 · 상태 · 방제팀 · 용역팀).
- 코드 옆 배지: **승인 대기**(등록 승인 전 — 아직 쓰지 않음), **반려**, **이카운트 미등록**(승인됐지만 이카운트에 아직 없음), **이카운트 등록됨** 등. 배지에 마우스를 올리면 설명이 나옵니다.

### 새로 추가 — [신규 추가]
1. 분류(대분류·중분류)·제품명·용량·가격을 넣으면 **예상 코드**가 나옵니다 (확정은 저장할 때).
2. 비슷한 이름이 있으면 확인 창이 뜹니다. 같은 제품이면 취소하고 있는 것을 쓰세요. 용량이 다르면 새 품목이 맞습니다.
3. 글로벌 DB 웹에서 만든 것은 **승인 없이 바로 확정**됩니다. 이카운트에는 따로 등록해야 합니다 (아래 '이카운트 비교').
- 기타 코드 화면에서는 잔디·기타물품만 만들 수 있습니다. 운반비 같은 기타(E) 코드는 이카운트에서 만든 뒤 [이카운트 비교]로 가져옵니다.

### 고치기
- 줄을 **더블클릭** → 수정 창. 바꾼 칸만 저장됩니다. 다른 사람이 먼저 고쳤으면 "다른 곳에서 먼저 고쳤습니다"가 뜨고 최신 내용을 다시 보여 줍니다.
- **별칭**: 현장에서 부르는 이름(예: 데브리놀)을 더합니다 — 재고·견적 봇이 이 이름으로도 찾습니다. 바로 저장됩니다.
- **변경 이력**: 누가 언제 무엇을 바꿨는지.
- 대분류·중분류는 코드 체계와 묶여 있어 바꾸면 한 번 더 확인합니다.

### 엑셀로 한꺼번에 고치기
1. 필터로 고칠 것만 남기고 **[엑셀 다운로드]** — 보이는 목록 그대로 받습니다.
2. 엑셀에서 가격·중요도·사용 등을 고칩니다. **코드 열과 '마지막 수정' 열은 고치지 마세요.**
3. **[엑셀 업로드]** → 바뀐 칸만 미리 보여 줍니다 → 확인하고 **[선택 저장]**.
- 내려받은 뒤 다른 곳에서 고친 품목은 '다운로드 후 수정됨'으로 표시되고 기본으로 빠집니다. 새 품목 추가·삭제는 엑셀로 하지 않습니다.

### 이카운트 비교
- 이카운트 품목등록 엑셀(ESA009M)을 올리거나 **[서버 데이터 불러오기]**(관리자가 미리 올려 둔 이카운트 품목)를 누릅니다.
- **신규** 탭: 이카운트에만 있는 품목 → 골라서 **[선택 추가]**.
- **이카운트 미등록** 탭: 여기서 만들고 승인된 품목 중 이카운트에 아직 없는 것 → **[엑셀 다운로드]** 로 받아 이카운트에 등록 → 다시 비교했을 때 이카운트에 있으면 **[등록 완료로 반영]**.

## 3. 거래처정보

- 검색(거래처명·코드·대표자·별칭), 필터(분류 · 사용 · 출처). 분류: 골프장 · 매입처 · 매출처 · 잔디농장 · 기타.
- **[신규 추가]**: 법인은 사업자등록번호 10자리가 거래처 코드가 됩니다(이미 있으면 알려 줌). 개인은 `P00001` 처럼 자동. **주민등록번호는 넣지 않습니다.** 사업자등록증 등 증빙 파일을 같이 올릴 수 있습니다(기록용).
- 줄 더블클릭 → 수정·별칭·변경 이력. 이카운트에서 온 거래처의 이름·대표자·업태·종목을 고치면 **'이카운트 반영 필요'** 배지가 붙습니다 — 이카운트에서도 똑같이 고치세요.
- **[이카운트 엑셀 비교]**: 이카운트 거래처등록 엑셀(ESA001M)을 올리면 신규 / 변경 / 이카운트 미등록 / 이카운트 반영 필요 탭으로 나눠 보여 줍니다. 골라서 반영하고, 이카운트에 등록·반영을 마친 것은 [등록 완료로 반영]·[반영 완료로 표시].

## 4. 창고 · 맵코스 · 방제작업코스 — 용역 현장 짝

용역 현장 하나는 **방제작업코스(GC) 한 줄**이 원본입니다. 골프장(맵코스)·창고 화면은 GC 를 골라 거기 값을 불러옵니다.

1. **방제작업코스** → 수정: 맵코스(골프장), **고객사 거래처**(이름·사업자번호로 검색), **용역창고**(창고 목록에서)를 고릅니다.
2. **창고정보** → 용역 창고 줄 더블클릭 → 방제작업코스를 고르면 골프장이 GC 에서 채워집니다. 한 GC 에는 창고 하나만.
3. **맵코스** → 연필 → 방제작업코스를 고르면 고객사가 GC 에서 채워집니다 (바꾸려면 방제작업코스 화면에서).

- GC 를 바꾼 뒤에는 그 골프장·창고 창을 한 번 열어 저장해야 사본이 맞춰집니다.
- 골프장·방제작업코스 목록은 파일 하나라 **두 사람이 동시에 고치면 나중 저장만 남습니다.** 함께 고칠 때는 순서를 정하세요.
- 창고 [이카운트 엑셀 비교]는 이카운트 창고등록 엑셀(ESA005M)로 합니다.
- 자세한 규칙: [용역현장_짝_창고-골프장-거래처.md](용역현장_짝_창고-골프장-거래처.md)

## 5. 등록 요청 — 승인하기

재고·견적 앱(봇·웹)에서 새 품목·거래처를 만들면 **등록 요청**이 됩니다. 코드는 바로 생기지만, **승인 전에는 앱이 그 코드를 쓰지 않습니다** (예외: 견적은 거래처를 승인 대기에도 견적에 씀 — '견적에서 사용 중' 표시).

| 종류 | 무엇을 승인 |
|---|---|
| 증빙 없는 거래처 · 새 품목 | **등록 + 이카운트 등록**을 한 번에 — [✅ 승인 (등록 + 이카운트)] 또는 [❌ 반려] |
| 증빙(사업자등록증·세금계산서 등)으로 자동 등록된 거래처 | 등록은 끝남. **이카운트에 올릴지만** — [✅ 이카운트 등록 승인] 또는 [🚫 이카운트 제외] |

- 웹 **등록 요청** 화면: 탭(승인 대기 · 증빙 자동 등록 · 승인 · 반려·제외 · 전체), 필터(종류 · 앱). 승인자로 로그인하면 줄마다 결정 버튼이 보입니다.
- 줄을 누르면 증빙 사진과 읽은 값, 요청자·요청한 앱이 나옵니다. 오타는 **[정보 수정]** 으로 고친 뒤 승인하세요.
- 반려·이카운트 제외는 **사유**를 적어야 합니다. 반려하면 그 코드는 사용 안 함(N)이 되고 지우지는 않습니다.
- 결정은 웹·봇 어디서 해도 한 번만 남습니다. 결과는 요청한 앱이 요청자에게 알립니다.
- 승인 뒤에는 이카운트에 등록하고 [이카운트 비교 → 등록 완료로 반영].

## 6. 글로벌 DB 봇 (텔레그램 `@dsgreen_gdb_bot`)

승인자가 이동 중에도 승인할 수 있게 카드를 보냅니다.

- **연결**: 웹 **설정 → 내 텔레그램 연결 → [연결 링크 만들기]** → 휴대폰에서 [텔레그램 열기] → 봇 화면에서 **[시작]**. "연결됐습니다"가 오면 끝 (링크는 10분, 한 번만).
- **카드**: 등록 요청이 생기는 순간 옵니다. 버튼을 누르면 카드가 결정 문구로 바뀝니다.
  - [❌ 반려] · [🚫 이카운트 제외] → "사유를 보내 주세요" 메시지에 **답장**으로 사유를 보냅니다.
  - [📄 증빙 보기] → 증빙 파일을 보내 줍니다.
  - 이미 다른 곳에서 처리됐으면 "이미 처리됨"으로 바뀝니다.
- **명령**: `/pending` 승인 대기 목록(카드 다시 받기), `/help`.
- 매일 아침 8시에 승인 대기가 있으면 요약이 옵니다.
- 봇은 요청한 사람에게는 보내지 않습니다 (요청한 앱의 봇이 알림).

## 7. 설정 — 승인자 관리

| 역할 | 정하는 곳 | 할 수 있는 것 |
|---|---|---|
| **슈퍼관리자** | 서버 설정 (화면에서 못 바꿈) | 승인 + 승인자 추가·이름·빼기·초대 |
| **승인자** | 슈퍼관리자가 설정에서 추가 | 웹·봇에서 승인 |

- **승인자 추가** (슈퍼관리자): [+ 승인자 추가] → 글로벌 DB 웹 로그인 이메일과 이름(승인 기록에 남음) → 추가하면 **초대 링크**를 만들 수 있습니다. 링크를 그 사람에게 보내면, 텔레그램에서 [시작]을 눌렀을 때 연결됩니다(48시간, 한 번만).
- 연결되지 않은 초대는 '아직 연결 안 된 초대'에 남고 [초대 취소]로 거둡니다.
- [빼기]하면 승인 권한과 텔레그램 연결이 함께 없어집니다.
- 본인 이름을 [이름]으로 넣어 두면 결정 기록에 그 이름이 남습니다.

## 8. 인력 · 장비 · 기본정보

- **인력정보**: 이름 검색, 소속·분류 필터, [신규 인력], 더블클릭 수정, [삭제].
- **장비정보**: 분류·유형·담당부서 필터, [신규 추가] / [수정] / [삭제], 사진 올리기. 유지보수 건수를 누르면 이력.
- **기본정보**: 직급 · 조직 순서 · 날씨정보 · 조직 정보 · 장비 타입 · 휴일정보 · 타입 순서 · 장비 타입 순서를 고칩니다.
- **방제기본정보**: 조직 · 용역 · 작업 · 차량 정보 [추가] / [수정] / [삭제].
- 이 화면들은 저장할 때 목록·레코드를 통째로 저장합니다. 다른 사람과 동시에 고치지 마세요.

## 9. 자주 하는 일

**이카운트에 새로 만든 품목을 글로벌 DB 에 넣기**
약품정보(또는 기타 코드) → [이카운트 비교] → ESA009M 올리기 또는 [서버 데이터 불러오기] → 신규 탭에서 골라 [선택 추가] → 판가·중요도를 수정 창이나 엑셀로 채우기.

**글로벌 DB 에서 만든 품목·거래처를 이카운트에 올리기**
[이카운트 비교] → 이카운트 미등록 탭 → [엑셀 다운로드] → 이카운트에 등록 → 이카운트 엑셀을 다시 올려 비교 → [등록 완료로 반영].

**재고·견적에서 온 등록 요청 처리**
봇 카드 또는 웹 등록 요청 → 내용·증빙 확인(오타는 [정보 수정]) → 승인 / 반려(사유) → 이카운트 등록 → [등록 완료로 반영].

**가격을 한꺼번에 바꾸기**
필터 → [엑셀 다운로드] → 가격 고치기 → [엑셀 업로드] → 미리보기 확인 → [선택 저장].

**새 승인자 받기**
설정 → [+ 승인자 추가] → 초대 링크 보내기 → 상대가 [시작] → 목록에 ✈️ 표시 확인.

## 10. 문제가 생기면

| 증상 | 확인 |
|---|---|
| "다른 곳에서 먼저 고쳤습니다" | 최신 내용으로 다시 열렸습니다. 확인하고 다시 고치세요 |
